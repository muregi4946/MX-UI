# MX-UI signal cockpit design system

- **Role:** calm, high-signal network operations UI for one operator and their subscribers.
- **Visual lineage:** telephone exchange patch bay and oscilloscope, expressed as signal lamps, telemetry surfaces, and a restrained grid.
- **Type:** Red Hat Display for interface hierarchy, JetBrains Mono for machine data, Vazirmatn for Persian text.
- **Palette:** signal teal `#00c6b2`, deep teal `#008d80`, ink `#10201e`, upload navy `#2748a8`, Trojan violet `#6d5ce7`, attention amber `#ffcd12`, cut carmine `#b00014`.
- **Motion:** page arrival, soft signal lamp pulse, telemetry ring drift, hover lift, and reduced-motion fallback.
- **UX rules:** 44px minimum controls, visible focus rings, keyboard-safe dialogs, responsive collapse at 640px, no motion when the user requests reduced motion.
